Quick Info Table

**Basic Computer Components: What They Do**
Part Function
**CPU** The central processor that **executes all instructions and calculations**.
**RAM** **Volatile, temporary memory** used for currently running tasks and applications.
**HDD/SSD** **Permanent storage** where your operating system, files, and programs reside.

💡 **Essential Hardware Tip** Always check **component compatibility** (e.g., CPU socket type, RAM generation) before purchasing any computer parts!
