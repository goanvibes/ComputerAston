Keyboard (Input)

A primary text and command input device. Used for typing documents, entering data, and navigating applications via shortcuts.

Mouse (Pointing Device)

The essential device for graphical interface navigation. Allows users to select, open, and manipulate objects on the screen efficiently.

Headphones / Headset (Output)

An audio output device used for private listening to music, communication, or game sound effects.
